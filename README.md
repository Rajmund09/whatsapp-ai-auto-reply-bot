# WhatsApp AI Auto Reply Bot 🤖💬

An AI-powered desktop WhatsApp auto-reply bot built using **Groq LLM**, **PyAutoGUI**, and **Python**.  
It automatically detects new messages and replies like a real human.

---

## 🚀 Features
- Auto-detects new WhatsApp messages
- AI-generated natural replies
- Prevents replying to its own messages
- Desktop automation (no WhatsApp Web API needed)
- Lightweight & fast (Groq LLM)

---

## 🛠 Tech Stack
- Python
- PyAutoGUI
- Groq LLM (LLaMA 3.1)
- Pyperclip
- dotenv
